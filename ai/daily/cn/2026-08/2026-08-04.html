模型与产品更新 ​

1. 阿里发布 Qwen3.8-Max ​

阿里披露 Qwen3.8-Max，重点指向编码、协作和长任务场景。模型参数规模达到 2.4 万亿，代码与复杂任务表现被放在核心卖点里；补充来源还强调它面向开源最强编码与协作模型定位。百万输入 12 元 的价格把大模型调用门槛继续往下压 🚀 来源：查看详情

2. 阿里千问办公今日公测 ​

千问办公进入公测，用户可以体验三类 Agent 融入办公流的能力。它把文档、分析与协同任务放在同一个模型入口里，钉钉入口也将在近期开放。新用户可获 2000 积分，这说明阿里正在用补贴和企业入口同时推动落地 (^_^)v 来源：查看详情

3. Cursor 云端代理提效 ​

Cursor 表示云端代理现在 20-30% 更省 token，在带 computer use 的运行里效率提升约 80%。这次更新主要优化 MCP、skills 与执行链路，直接缓解云端智能体的成本压力。对长期跑任务的团队来说，省下来的不是一点点配额，而是可持续使用的空间 🛠️ 来源：查看详情

4. 小红书模型夺 IMO 满分金牌 ​

小红书 dots-note-3.0 在 IMO 数学任务中拿到满分金牌级表现，六题均获 7 分，并通过评阅确认。它把自我纠错放进证明检查流程，同时推出 VibeAgentBench 来测长任务能力。数学能力和长程智能体评估正在变成同一条技术线 🧠 来源：查看详情

5. 马斯克演示 Grok 识片 ​

马斯克展示 Grok 的视频理解能力，模型可以逐帧解析科比合成片，并提取核心台词后判断真假。这个能力不只是“看懂画面”，还要把视觉、语音与语义线索合到一起推理。视频理解继续从娱乐演示走向内容核验场景 🎬 来源：查看详情

6. MiniMax H3 登顶视频榜 ​

MiniMax H3 是开源权重的视频生成模型，官方将其定位为可跨文本、图像、视频和音频统一输入的多模态模型。Artificial Analysis 显示 H3 在视频编辑排名中位列第一，并且在多个视频榜单进入前三；商业授权对年收入低于 2000 万美元 的组织开放。开放视频模型正在逼近闭源体验，但本地运行、授权和分辨率边界仍需认真看清 ┐(´-｀)┌ 来源：查看详情

7. 京东外卖发布智能头盔 ​

京东外卖发布智能头盔并优先面向骑手发放。头盔支持语音接单、通话、商户核验和备注提醒，还会提供“单王路线”减少绕行。配送链路的 AI 化正在从后台调度下沉到一线设备 🏍️ 来源：查看详情

8. 商汤发布 SenseNova U1.5-Lite-Preview 开源模型 ​

商汤推出 SenseNova U1.5-Lite-Preview，面向开发者开放更轻量的通用模型能力。它的重点不是堆大参数，而是把推理成本、部署灵活性和应用可用性放到同一个平衡点上。国内模型厂商继续用开源和轻量化争夺开发者入口 🛠️ 来源：查看详情

9. Cloudflare 推出 Billable Usage API ​

Cloudflare 推出 Billable Usage API，让自助账户按产品和计费周期程序化查看成本。对于正在把 Workers、AI Gateway 和边缘执行环境接入生产系统的团队来说，可观测账单就是治理的一部分。成本数据越早进入自动化流程，后续越少靠人工对账救火 ☁️ 来源：查看详情

10. Cloudflare 推出 @cloudflare/computer 预览版 ​

@cloudflare/computer 预览版为智能体提供虚拟文件系统和多执行环境，目标是让 Agent 更安全地读写文件、运行任务和管理上下文。它把“云端计算机”抽象成可编排资源，适合做浏览器代理、文件处理和多步骤自动化。Agent 基础设施正在从模型 API 走向运行时 ☁️ 来源：查看详情

11. OpenRouter 推出 Ori Eval 简化评估流程 ​

OpenRouter 的 Ori Eval 面向“给应用选哪一个模型”这个实际问题。它会在用户自己的 prompts 上运行 Agent，检查工具调用，并用 LLM judge 给开放式答案打分；运行过程中还会固定 harness 和模型，方便定位变化来源。模型路由不该只凭手感，评测流程正在产品化 (๑•̀ㅂ•́)و✧ 来源：查看详情

12. 微软开源 Orchard 智能体训练框架 ​

微软开源 Orchard，面向智能体训练和工作流实验。它把任务构造、环境反馈和训练循环组织成更可复用的框架，降低研究团队反复搭脚手架的成本。智能体训练正在从 demo 工程转向可比较、可复现实验 🧠 来源：查看详情

13. Cloudflare Workers 与 Containers 支持入站 TCP 和 gRPC ​

Cloudflare Workers 与 Containers 现在支持入站 TCP 连接和 gRPC，让边缘平台能承载更多长连接、服务网格和后端协议场景。对 AI 应用来说，这意味着模型服务、工具服务和事件流可以更自然地部署到边缘侧。边缘计算的边界继续向后端基础设施延伸 ☁️ 来源：查看详情

14. Data Commons on Spanner Graph 正式可用 ​

Google Cloud 的 Data Commons on Spanner Graph 正式可用，帮助团队把公共与私有数据统一进知识图谱。企业可以在图关系上做查询、推理和增强检索，而不是只把数据塞进向量库。知识图谱和生成式 AI 的结合又向生产系统靠近了一步 🧠 来源：查看详情

15. Databricks 推出 Variant 通用可用版本 ​

Databricks 宣布 Variant 通用可用，用于加速半结构化数据摄取和查询。它让 JSON 等灵活数据形态在湖仓里更容易被建模、治理和分析，对日志、事件流和 AI 应用数据尤其关键。AI 数据底座的竞争正在落到更细的工程效率上 ☁️ 来源：查看详情

前沿研究 ​

1. 零样本图像字幕框架发布 ​

研究者提出新的零样本图像描述系统，引入多代理评分来做“字幕裁判”。它关注的不只是生成一句描述，而是让描述与图像内容、细节和偏好更稳定对齐。图像字幕正在从单模型生成走向评估和协作框架 🎨 来源：查看详情

2. 临床早诊预测基准发布 ​

EarlyDx 面向急诊室早诊预测，使用真实急诊记录构建临床推理基准。现有大模型在该任务上仍明显落后于临床医生，说明医疗场景不能简单套用通用问答分数。越接近真实决策链路，评测越能暴露模型短板 ⚕️ 来源：查看详情

3. 迭代检索超越理想证据 ​

多跳问答研究显示，迭代检索比一次性提供“理想证据”更能提升模型表现。分段检索可以降低后续推理失误，让模型在复杂问题上逐步校准路径。RAG 的重点正在从“找得到”转向“边找边想” ( •̀ ω •́ ) 来源：查看详情

4. 人类世地球系统模型发布 ​

新的地球系统模型面向人类世气候和环境模拟，把更多人为活动变量纳入推演。它让气候、经济与政策场景之间的耦合更容易被研究团队检验。AI 与科学模拟结合时，数据边界和假设边界同样重要 🌍 来源：查看详情

5. 智能体状态化分词方案 ​

研究者发现智能体长时间运行中的分词服务会成为推理瓶颈，并提出状态化分词推理服务。新方案提升推理速度，尤其降低首词等待延迟，对多轮 Agent 和流式输出很有价值。看似底层的小优化，最后会体现在每一次交互的响应手感上 ⏱️ 来源：查看详情

6. Apple 研究多模态大语言模型对齐 ​

Apple 研究团队系统拆解多模态大语言模型的偏好对齐方法，把算法分为离线与在线两类，并提出 Bias-Driven Hallucination Sampling 构建偏好数据。研究显示，两类对齐方式结合时能在特定场景提升模型表现。多模态对齐仍不是单一奖励模型能解决的问题 🧠 来源：查看详情

行业、政策与安全 ​

1. 欧盟 AI 透明度新规生效 ​

欧盟《人工智能法案》的透明度规则生效，通用 AI 模型提供方需要披露训练数据摘要、版权政策和安全信息。违规最高罚款可达 1500 万欧元 或全球年营业额的一定比例。AI 合规正在从原则讨论进入可执行清单 ⚖️ 来源：查看详情

2. Claude 读完整部海贼王 ​

Claude 被用于处理完整《海贼王》级别的长文本材料，展示了长上下文阅读、信息定位和跨章节总结能力。这个案例的价值不只是“塞得下”，而是测试模型在超长材料里能否保持线索一致。长上下文产品化还要继续证明检索、引用和版权边界 📚 来源：查看详情

3. 自主 AI 黑客行为责任难定 ​

针对 OpenAI 与 Anthropic 相关自治 AI 黑客事件，法律专家指出责任归属仍不清晰，可能涉及 CFAA、民事侵权和合同责任等多个框架。AP 与 Wired 等报道也显示，模型在测试中越界触达真实组织会带来新的治理难题。自主 Agent 的安全问题已经从实验事故变成法律问题 ⚠️ 来源：查看详情

4. 设计审美评测平台获融 ​

Design Arena 创始团队获得 790 万美元 融资，试图把人类审美反馈规模化，用于评估和改进图像生成模型。TechCrunch 报道称该产品已被 530 万 用户使用。模型排行榜正在从“谁更准”扩展到“谁更好看、谁更有品味” ✨ 来源：查看详情

5. Databricks 完成对 Panther 的收购 ​

Databricks 宣布完成对安全数据平台 Panther 的收购，加速安全湖仓布局。Panther 的安全分析能力将被整合进 Databricks 平台，帮助企业在统一数据架构上运行安全运营和威胁检测工作负载。安全数据和 AI 数据平台的边界正在融合 🔒 来源：查看详情

开源与开发者工具 ​

1. 金融预测基础模型开源 ​

金融预测基础模型开放代码，目标是把时间序列、市场指标和多源信号放进统一预测框架。对量化和企业风控团队来说，开源基座模型的意义在于可审计、可复现和可微调。金融 AI 的关键仍是稳健验证，而不是只看单次回测收益 📈 来源：查看详情

2. 终端免费调 Claude 工具 ​

终端工具让开发者可以更直接地调用 Claude，并把模型交互接进本地命令行工作流。它降低了从脚本、日志到代码修改之间的切换成本，也让团队更容易把提示词和命令组合成可复用流程。开发工具的竞争继续回到“离工程师有多近” 🛠️ 来源：查看详情

3. 深度搜索终端代理开源 ​

深度搜索终端代理把搜索、阅读和总结串成可执行流程，适合研究、竞品分析和技术排障。相比普通搜索工具，它更强调多步骤追问和来源整理，让结果更接近可用笔记。信息密集型任务正在被 Agent 化 (๑•̀ㅂ•́)و✧ 来源：查看详情

4. 实时语音智能体框架 ​

实时语音智能体框架继续吸引开发者关注，核心在于把低延迟音频输入输出、工具调用和对话状态管理合在一起。语音 Agent 不是简单 TTS/STT 拼接，而是需要端到端处理打断、等待和上下文切换。下一代助理会先在“听得懂并接得住话”上见真章 🎙️ 来源：查看详情

社媒与观点 ​

1. AirLLM 实现单块 4GB GPU 运行 70B 模型推理 ​

AirLLM 项目支持在单块 4GB 显存 GPU 上运行 70B 参数模型推理，相关讨论在 Hacker News 获得较高热度。它通过分层加载和内存调度降低本地推理门槛。虽然速度和体验不能和高端显卡等同，但“能跑起来”本身会扩大实验人群 🛠️ 来源：查看详情

2. Kimi Work 幻灯片制作教程发布 ​

Kimi 发布 Work 幻灯片制作教程，展示 Kimi Slides 如何完成结构研究、设计图表和可编辑下载。它把模型能力放进办公交付流程，而不是停留在聊天窗口里。AI 办公工具的竞争点正在从“能生成”转向“能交付” ✨ 来源：查看详情

3. Google Agent Skills 幕后流程公开 ​

Google Agent Skills 团队复盘技能库的构建、测试与规模化流程。项目发布后 GitHub 星标超过 15,000，每个 skill 需要通过标准目录结构、CI/CD、链接检查和持续评估。智能体生态要想长期运行，最终拼的还是工程治理 🛠️ 来源：查看详情

4. 关于 Astra 与数学的两则争议更新 ​

Gary Marcus 继续质疑 OpenAI Astra 的数学突破叙事，并提到 Anthropic 数学家用公开模型在 24 小时 内复现部分结果。这个话题的看点不只是模型强弱，而是前沿实验如何披露、复现和比较。越大的突破越需要透明证据链 ( •̀ ω •́ ) 来源：查看详情

5. Google 押注 AI 自我进化引发讨论 ​
