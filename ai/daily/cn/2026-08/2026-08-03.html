2026-08-03 AI大事件

今日摘要 ​

Thinking Machines 开放 Inkling 多模态权重，OpenAI Presence 把企业智能体推进托管部署 🚀
谷歌 TPU 8t/8i、英伟达 Molt 与 Grok 视频分析继续刷新算力、训练和多模态产品边界 ☁️
TaoMate、Stream3D、模型意识表述与视觉因果基准集中抬高前沿研究密度 🧠

模型与产品更新 ​

1. Inkling 开放多模态权重 ​

Thinking Machines 发布 Inkling 多模态模型，并披露 2760 亿总参数、仅激活 120 亿参数的小版本权重。模型原生处理文字、图像与音频，NVFP4 量化后可在单张 B300 上运行；这让开放权重多模态模型从“能看图”继续走向更接近统一输入接口的形态 🚀。来源：官方模型技术发布详情

2. OpenAI Presence 推进企业智能体 ​

OpenAI Presence 面向高规模、高风险工作流，提供托管式企业智能体部署，重点覆盖客服、语音和内部流程。它不是自助式产品，而是由 OpenAI 或部署伙伴配合完成系统接入、权限、评测、灰度和监控；这说明企业智能体的竞争点正从单个模型能力转向上线后的治理和持续改进 ( •̀ ω •́ )。来源：OpenAI Presence 说明、企业智能体报道

3. 英伟达开源 Molt 框架 ​

Molt 是英伟达发布的 PyTorch 原生智能体强化学习框架，核心代码约 8.6K 行，并组合 Ray 与 vLLM 支撑训练。它的价值在于把普通 Python 代理直接接入强化学习流程，研究者可在 H100 上复现实验，降低“智能体训练框架”从论文到工程的门槛 🛠️。来源：Molt 发布报道

4. 谷歌发布八代 TPU 双芯 ​

谷歌云公开 TPU 8t 与 TPU 8i 技术细节：前者面向大模型训练，集群规模可达 9600 芯片与 2PB 内存；后者主攻低延迟推理，并强调 80% 性价比提升。训练与推理芯片分化越来越清晰，Agent 服务的成本结构也会跟着重算 ☁️。来源：谷歌云官方解读

5. Grok 支持分析任意视频 ​

Grok 新增视频理解演示，用户可把动态视频交给模型分析并继续追问。这个能力把多模态交互从图文扩展到动态内容，适合快速理解素材、提取动作线索或复盘片段；但长视频、复杂剪辑和边界场景仍需要更多真实测试 ✨。来源：Elon Musk 发布原文

前沿研究 ​

1. TaoMate 稳定分钟级数字人 ​

阿里与南京大学提出 TaoMate，用 221 亿参数支撑流式音视频数字人生成。框架通过锚点记忆压制长视频中的身份和画面漂移，三卡推理可达 35 帧；如果后续开放足够稳定的工程实现，直播数字人和长时虚拟主播会更接近可用 🧠。来源：数字人生成论文

2. Stream3D 补全流式三维 ​

Stream3D 面向连续视角三维补全，从视频流中逐步提取空间证据，并用固定容量记忆维持场景状态。论文给出的 GSO 测试 CD 降至 0.048，说明实时三维理解不一定要反复重训模型；更像是在给机器人和空间应用补一套可滚动更新的世界记忆 ( •̀ ω •́ )。来源：流式三维研究论文

3. 谷歌研究模型意识表述 ​

谷歌研究团队用激活干预分析模型的心智自认、价值和情绪回答，移除拒答向量后相关得分升至 4.77。这里的重点不是证明模型“有意识”，而是说明模型对自我、价值和情绪类问题的输出可以被内部表征显著调节，评测设计会影响公众对模型能力的判断 🧪。来源：模型意识研究论文

4. CausalVLBench 测试视觉因果 ​

CausalVLBench 为多模态模型加入因果干预与反事实任务，覆盖视觉场景中的“如果改变一个条件会怎样”。现有多模态模型在这类任务上仍明显吃力，配套代码虽然只有 ⭐4，但可复现实验比单纯展示 demo 更重要；视觉理解正在从识别物体走向推理关系 🧩。来源：视觉因果评测论文

行业、政策与安全 ​

1. Jeff Dean 研判智能体方向 ​

Jeff Dean 在访谈中判断，智能体仍会经历长期试错，算力瓶颈、上下文工程和产品品味会成为创业者真正绕不开的问题。他把 TPU 经验带回模型创业讨论：先找清楚模型盲区和系统约束，再决定产品形态，这比单纯追逐“更会写代码”的演示更稳 (๑•̀ㅂ•́)و✧。来源：模型创业趋势访谈

2. Cloudflare 开启 Agents Week ​

Cloudflare 启动 Agents Week，核心问题是“Agent Cloud”应该长什么样。它认为现有云和网络主要为人类浏览器设计，而智能体需要更快的执行层、清晰的访问边界、安全控制和代理间网络；这类基础设施会决定智能体能否从单应用插件变成可运营系统 ☁️。来源：Cloudflare 官方说明

3. DeepSeek 价格战继续升温 ​

围绕 DeepSeek V4 Flash 的讨论继续发酵，低价模型让“AI 能力接近商品化”的判断更有现实压力。Axios 将其描述为模型价格战继续加速，AIHOT 聚合也显示 DeepSeek 官方 API、开源许可和多家信源集中跟进；对开发者来说，下一步可能不是只选最强模型，而是建立按任务路由的成本策略 📉。来源：DeepSeek 价格战报道、DeepSeek API 更新索引

开源与开发者工具 ​

1. MindMemOS 让记忆持续进化 ​

华为诺亚开源 MindMemOS，把记忆从单个智能体中解耦出来，用三维结构保存状态与演化轨迹。它在双榜成绩达到 94.03 与 70.63%，适合观察“长期记忆层”如何从聊天记录整理走向可迁移的智能体基础设施 🧠。来源：智能体记忆开源仓库

2. AirLLM 突破显存限制 🌟25.6k ​

AirLLM 聚焦低显存大模型推理，支持 700 亿模型在 4GB 显卡上运行，仓库累计约 25.6k 星标，单日新增 819 颗星。它解决的是很朴素的问题：不用昂贵云卡，也能把大模型部署到个人或小团队环境里试起来 🛠️。来源：轻显存推理项目主页

3. k-skill 深耕韩国本地语境 🌟6.9k ​

k-skill 为智能体补齐韩国本地任务能力，仓库收录本地语境、服务流程和实用工具，累计约 6.9k 星标，单日新增 177 颗星。它提醒开发者，智能体生态不只拼通用模型能力，本地语言、平台习惯和工作流细节同样能形成壁垒 🌏。来源：韩国智能体技能仓库

4. ds4 支持多端本地推理 🌟19.9k ​

ds4 让 DeepSeek4 登陆本地设备，兼容 Metal 与多类显卡后端，仓库累计约 19.9k 星标，单日新增 139 颗星。多硬件后端的意义在于减少云端依赖，让不同设备都能参与推理实验，尤其适合预算敏感的个人开发者和小团队 (^_^)v。来源：多端推理开源仓库

社媒与观点 ​

1. Kimi K3 开源模型深读 ​

一篇技术深读把 Kimi K3 放在开放模型竞争中拆解，重点关注 2.78 万亿参数、KDA 长上下文能力与稳定 MoE 训练。它更像是一篇研究笔记而非发布新闻，价值在于帮读者看清模型规模、路由结构和工程权衡如何共同影响开源模型上限 🧭。来源：技术深读全文

2. AGI Bar 免费 token 上线 ​

北京 AGI Bar 开始提供店内免费 token 服务，用户进店连 WiFi 即可调用，先供应 DeepSeek V4 Flash，并称后续上海店也会接入。这个案例有点像把本地推理变成线下体验入口：技术不再只在云端控制台里，也可以成为门店获客和社区运营的一部分 🔌。来源：即刻发布原文

3. 谷歌错过 LMChat 窗口 ​

围绕 LMChat 的讨论再次升温：OpenAI 产品负责人 Tibo Sottiaux 称自己曾参与 Google 内部聊天机器人项目，时间大约早于 ChatGPT 一年，但产品没有对外发布。独立报道也将其放到 LaMDA、Meena 和搜索业务包袱的背景下解读；这条更适合作为发布节奏与组织风险的案例，而不是简单归因成技术输赢 ┐(´-｀)┌。来源：Tibo 原帖、LMChat 独立报道

4. Astra 数学表现引发质疑 ​

Gary Marcus 对 OpenAI 内部测试模型 Astra 的数学表现提出质疑，认为“擅长某类数学题”不能自动外推为擅长所有数学、科学或认知任务。数学任务适合符号验证，也更容易生成大量合成数据；在方法细节未公开前，这类跑分叙事需要保持克制 🧮。来源：Gary Marcus 评论

5. 开源模型盘点聚焦 Inkling 与 Kimi K3 ​

Nathan Lambert 的开放模型盘点把 Laguna S2.1、Inkling 与 Kimi K3 放在同一张“开放 artifact”图谱里。它补充了今天 Inkling 发布之外的观察：开放模型的竞争不只看单次发布，还要看权重、推理成本、社区复现和后续迭代能否形成帕累托前沿 ( •̀ ω •́ )。来源：开放模型盘点

今日总结与启示 ​

  • 企业智能体进入治理阶段。 Presence 和 Cloudflare Agents Week 都在强调权限、评测、监控与基础设施，说明智能体落地已经绕不开生产工程 🚀。
  • 多模态和算力继续分层。 Inkling、Grok 视频分析、TPU 8t/8i 共同指向一个趋势：输入更统一，底层硬件却更专业化 ☁️。
  • 研究开始补齐长程一致性。 TaoMate 的锚点记忆、Stream3D 的固定容量记忆和视觉因果基准都在处理“连续世界”问题 🧠。
  • 开源项目更偏实用基础件。 MindMemOS、AirLLM、k-skill、ds4 都不是纯展示项目，而是在帮开发者解决记忆、本地化、显存和设备适配 🛠️。
  • 行业叙事要看证据强度。 LMChat、Astra 和 DeepSeek 价格战都很热，但真正值得跟进的是可核验来源、成本曲线和可复现指标 (๑•̀ㅂ•́)و✧。
