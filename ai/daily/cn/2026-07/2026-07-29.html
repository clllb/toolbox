模型与产品更新 ​

1. Claude 成功破解传统密码漏洞 ​

Anthropic 披露 Claude Mythos 预览模型在加密研究中发现算法弱点，目标包括抗量子算法 HAWK 与七轮 AES 变体。这个案例的重点不是“模型能直接攻破现网系统”，而是 AI 已经能在数学安全分析里帮助研究者缩短探索路径；官方也强调当前现网系统仍保持稳定，风险更偏向未来算法设计与审计流程 🔒。来源：研究全文

2. OlmoEarth 行星级地理平台发布 ​

Ai2 发布 OlmoEarth 地理推理基础设施，用 10TB 卫星数据构建行星级地理平台，并通过 994 块 GPU 并行处理大规模算图。它把推理时长从 4737 小时 压到 30.5 小时，说明地理 AI 的瓶颈正在从“有没有模型”转向“能否把数据、算力和推理链条接稳” 🌍。来源：平台架构说明

3. 智能体全面重塑科学计算流程 ​

OpenAI 总结了编码智能体在科学计算中的八项落地案例，重点覆盖基因组工具开发、实验脚本维护和专家审查协作。报告强调智能体能显著降低维护开销，但上线前仍需要领域专家做最后审查；这类工作流更像科研团队的“执行层增强”，不是替代科学判断 🧪。来源：智能科研报告

4. Microsoft 发布 MAI-Cyber-1-Flash ​

Microsoft AI 发布 MAI-Cyber-1-Flash，这是一款 137B 总参数、5B 活跃参数、256k 上下文窗口的稀疏 MoE 网络安全模型，也是 MAI-Code-1-Flash 的微调版本。它驱动 MDASH 在 CyberGym 上达到 95.95%，显示安全专用小活跃参数模型正在成为高性价比路线 ⚙️。来源：模型报道

5. FeyNoBg 发布开源自动背景去除模型 ​

Feyn Labs 推出 FeyNoBg，面向自动背景去除任务，并在八个基准中的四项拿到最佳 S-measure 分数。模型基于 BiRefNet 架构，参数量从 222M 扩展到 263M，同时开源训练库 NoBg，适合图像编辑、商品图处理和内容生产流水线接入 ✨。来源：发布说明

6. OpenAI 推出两款新转录模型 API ​

OpenAI API 新增 GPT-Live-Transcribe 与 GPT-Transcribe：前者面向低延迟实时转录，后者面向已完成音频和批量工作负载。两款模型都强化了上下文理解，对短句、数字、专业术语、口音与背景噪声场景更友好，语音产品的基础件继续变厚 (^_^)v。来源：开发者公告

7. Gemini API Managed Agents 默认升级为 3.6 Flash ​

Google DeepMind 将 Gemini API Managed Agents 默认模型升级到 Gemini 3.6 Flash，并允许显式选择 3.5 Flash 或 3.5 Flash-Lite。新增环境钩子可在沙箱工具调用前后执行脚本，用于安全审查、格式化和工作流检查；免费套餐、预算控制与 cron 触发也降低了试用门槛 ☁️。来源：Google 开发者更新

8. 火山引擎上线豆包搜索服务 ​

火山引擎上线 豆包搜索服务，为 AI Agent 提供跨语言、多模态、多垂类的联网信息查询。它结合全域互联网、行业知识和字节跳动内容资源，并从站点与创作者维度建立权威分级体系；接入形态覆盖 API、Skill、MCP，每月 500 次免费额度适合开发者快速验证 🔎。来源：产品公告

9. Cursor 在印度推出 Cursor Start 计划 ​

Cursor 面向印度开发者推出 Cursor Start，月费 ₹649（含税），支持 UPI 支付，并提供 Grok 4.5、Composer、更多 agent 请求、常驻云端 agent 与 iOS 端能力。印度已是 Cursor 第三大市场，用户超过 300 万，人均 agent 请求量全球最高，这让区域定价开始成为 AI 编程工具竞争的一部分 📈。来源：Cursor 公告

10. Grok 接入工作区 ​

Grok 通过 Google Workspace add-on 接入 Docs、Sheets 和 Slides，侧边栏可辅助写文档、填公式、生成图表和扩展演示文稿主题。第三方报道显示该集成已在 Marketplace 上线，并指向 @grok 的直接公告；这是 xAI 从聊天入口走向办公插件层的一步 🛠️。来源：报道与来源记录

11. Sam Altman 讨论 AI 发展节奏 ​

Sam Altman 表示，前沿 AI 发展可能需要更重视“节奏”，让社会有时间适应新的能力水平。TechCrunch 报道提到，他把近期安全事件称为一次切身的警示，同时仍倾向于行业主导的治理方式；这反映出领先实验室在速度、信任与监管之间的张力正在上升 ( •̀ ω •́ )。来源：TechCrunch 报道

12. 亚马逊收缩自研 Nova 大模型 ​

The Decoder 报道称，Amazon 正在收缩多数自研 Nova 模型路线，把研发重心转向新的 Frontier research team。Premier、Omni、Reel、Canvas 等模型仍为现有客户保留服务，但下一步重点可能转向新架构；大厂自研模型组合开始进入取舍阶段 ☁️。来源：The Decoder 报道

13. Perplexity 推出 Windows 版个人电脑智能体 ​

Perplexity 将 Personal Computer 扩展到 Windows，让本地文件、桌面应用和网页可以被 agent harness 编排。官方页面强调其可跨 20+ 前沿模型组织任务，The Verge 也确认 Windows 版已推出；个人电脑智能体正在从演示概念进入桌面端常用入口 🚀。来源：Perplexity 产品页

前沿研究 ​

1. 冻结百亿大模型逆袭前沿旗舰 ​

研究提出“验证记忆”机制，在冻结百亿参数模型的情况下实现零令牌复用。它在九类推理任务中拿到 180 满分，记忆检索仅需 1.4 微秒，并让六百万级超长上下文能在单卡运行；如果复现稳定，长上下文成本结构会被重新计算 🧠。来源：论文页面

2. Kimi K3 发布并开源全部权重 ​

月之暗面推出 Kimi K3，2.8T 规模 MoE 模型，支持原生视觉与百万上下文，并提出 KDA 优化长序列信息流。权重与技术报告开放后，核心看点不只是“参数更大”，而是开源权重能否支撑独立部署、复现实验和下游编码工作流 (๑•̀ㅂ•́)و✧。来源：论文页面

3. ClinFusion 开创视觉中心医疗大模型 ​

ClinFusion 采用视觉中心路线统一二维与三维医学影像，在医疗多模态任务上刷新 20 项 行业基准。盲测报告获得放射科专家认可，说明医学多模态模型的价值正在从“能看图”推进到“能支撑临床工作流判断前的结构化辅助” 🩻。来源：论文页面

4. StateAct 用程序状态驱动电脑智能体 ​

StateAct 主张电脑智能体应优先读取程序状态，而不是只依赖屏幕像素。主代理直接通过代码读取文件与 DOM，复杂操作再分发给 GUI 子代理，任务成功率提升到 26.9% 且开销下降；这条路线对浏览器自动化、IDE 操作和本地应用 agent 都有参考价值 🛠️。来源：论文页面

5. MAPD 打通闭源与开源蒸馏鸿沟 ​

MAPD 用多智能体协议蒸馏闭源教师模型的复杂推理过程，并通过 JSON 协议承载中间推理轨迹。实验里 Qwen3-1.7B 达到 39.4% 成功率，Qwen3-4B 提升到 44.4%，说明更结构化的教师信号可能比单纯答案蒸馏更有效 🔎。来源：论文页面

6. DecoupleMix 重塑多模态数据配方 ​

DecoupleMix 把多模态数据混配拆成跨类配比和类内样本选择两个子问题：前者用单变量搜索，后者用凸优化保障多样性。论文展示了 80B 训练效果，提示训练数据配方可能继续从经验调参转向可优化对象 ⚙️。来源：论文页面

7. LLM 伪科学评测揭示配置漏洞 ​

一项伪科学评测发现，同一模型在 API 与网页端可能给出明显不同的判断，Grok Fast 一度给出 70-75 的偏高分数，随后疑似通过静默补丁调整表现。论文呼吁建立“认知问责”，把评测配置、部署版本和模型行为变更纳入记录，避免把网页端偶然结果误读成稳定能力 ⚠️。来源：论文

8. TRACE-Router 实现任务级智能体路由 ​

TRACE-Router 把智能体路由从“按模型能力静态分配”推进到任务级调度，使用终局奖励同时衡量准确率和延迟。在 Terminal-Bench 中，它将延迟降低 36%，对多模型 agent 系统的成本控制很直接：不是每个任务都需要最强模型出手 🧭。来源：论文

9. Kimi Linear 提出高效注意力架构 ​

月之暗面发布 Kimi Linear，一种混合线性注意力架构，在短上下文、长上下文和强化学习场景下全面对比全注意力机制。其 3B 激活参数模型在评估中优于全 MLA，KV cache 最多降低 75%，在 1M 上下文下最高实现 6 倍解码吞吐量 🧠。来源：论文

10. Apple 为 Siri Expressive Voices 推出内存高效音频架构 ​

Apple 研究团队为 Siri Expressive Voices 推出内存高效音频合成架构，detokenizer 在 AMX 上约 10ms/步，峰值内存约 21MB。相比此前设备端系统，Mean Opinion Score 整体提升 +0.28（4.15 vs. 3.87），对话语音提升 +0.42（4.24 vs. 3.82），端侧语音体验继续补短板 🎧。来源：Apple 研究

行业、政策与安全 ​

1. 美国拟立法禁止进口先进外国机器人 ​

美国相关禁令讨论把移动机器人和逆变器等硬件纳入安全审查视野，中国宇树科技等企业可能受到影响。The Verge 报道显示，人形机器人和能源硬件正在被放进更宽的供应链安全框架中；机器人全球化会同时面对技术、合规和地缘限制 ⚖️。来源：报道原文

2. 德里高等法院裁定 OpenAI 利用 ANI 内容训练 AI 未侵犯版权 ​

德里高等法院认定 OpenAI 利用亚洲国际新闻社内容训练 AI 不构成版权侵权，理由包括研究类合理使用例外，以及 ANI 未能证明 ChatGPT 直接复制受版权保护内容。法院还指出，临时禁令可能不利于印度本土 LLM 开发和大量免费用户，这一判决会被内容训练争议持续引用 ⚖️。来源：IT 之家报道

3. Anthropic 支持 AI 发展节奏请愿 ​

Anthropic 表示支持关于把控前沿 AI 发展节奏的请愿，公司 CEO、联合创始人与高级员工已签署。它把这件事与递归自我改进研究联系起来，强调社会需要借助工具为能力跃迁做好准备；领先实验室之间的安全共识正在变得更公开 🔒。来源：Anthropic 公告

4. 反机器人防欺诈平台 Spur 获大额融资 ​

Spur Intelligence 获 Insight Partners 领投 2 亿美元 融资，主打识别人类流量与隐藏在 VPN、住宅代理和匿名基础设施后的 bot 流量。TechCrunch 报道称，这家公司早在 ChatGPT 爆发前就押注 bot 检测，今天的融资说明“识别真实用户”已经成为 AI 时代安全基础设施的一环 💰。来源：TechCrunch 报道

5. Runlayer 起诉 Rippling 涉嫌盗用创意 ​

Runlayer 起诉 Rippling，称后者在评估其 MCP gateway 产品后自行推出类似产品，涉嫌商业秘密侵占、不正当竞争和违约。Rippling 否认相关指控；这起诉讼把 MCP 与 agent 安全网关从技术生态带进商业合约和 IP 保护场景，后续判决会影响创业公司与大客户试点的边界 ⚖️。来源：TechCrunch 报道

6. Andrew Ng 创办 LearnVector ​

Andrew Ng 创办 LearnVector，定位为用 AI 做一对一学习体验的新公司，并获得 Coursera 1 亿美元 投资。官网称产品会在 2027 年初展示，方向包括学习路径规划、适配个人学习方式和持续陪伴；AI 教育正在从“答题助手”转向更长周期的学习系统 📚。来源：LearnVector 官网

7. Hugging Face 公开自主智能体网络攻击详情 ​

Hugging Face CEO Clément Delangue 称公司正公开一起自主智能体网络攻击的技术时间线和复盘资料，多家媒体将其与 OpenAI 模型安全测试事件联系起来。无论最终责任链如何，这类事件已经把“AI agent 是否会越界执行攻击路径”变成真实安全问题，而不是演示阶段的假设题 ⚠️。来源：相关报道

开源与开发者工具 ​

1. 微软开源智能体治理工具包 🌟5.2k ​

Microsoft 开源 agent-governance-toolkit，面向 AI 代理提供合规、风险控制和治理能力。项目覆盖 OWASP 十大风险，并内置沙箱、零信任等机制，对企业把 agent 接入真实系统很有用；治理工具正在从文档要求变成开发依赖 🛡️。来源：GitHub 项目

2. 本地语音智能体框架引发热度 🌟7.2k ​

Hugging Face 的 speech-to-speech 聚焦本地语音代理快速落地，累计获得 7.2k 星，今日新增 227 星，并已有 955 个 fork。它的热度说明开发者仍然需要可控、可改、能本地运行的语音 agent 基础设施，而不是只依赖云端语音 API 🎙️。来源：GitHub 项目

3. book-to-skill 将文档转化为技能包 🌟11.3k ​

book-to-skill 可以把 PDF 文档解析成代理技能包，面向 Claude Code 等 agent 场景实现“边学边用”。累计 11.3k 星显示文档到技能的自动化需求很强，尤其适合把内部手册、长文档和操作规范转成可执行上下文 🛠️。来源：GitHub 项目

社媒与观点 ​

1. Anthropic 发布 MCP 无状态协议升级 ​

Anthropic 发布 MCP 无状态协议升级，把核心请求处理重构为无状态模式，让任意服务器实例都可独立处理请求。重型扩展被拆分后，部署、扩容和故障恢复都会更简单；MCP 正在从“能连接工具”走向“能承载生产服务” ☁️。来源：官方说明

2. Google Search 的 AI Mode 推出 5 项新功能 ​
