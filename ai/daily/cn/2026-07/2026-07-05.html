模型与产品更新 ​

1. Claude 科学科研平台发布 ​

Claude 科学科研平台发布。 团队推出了 科研机构的高效实验工具 测试版。该系统专门 🧪 针对复杂的 生命科学 研发。协同智能体能够自动运行多步实验流程。评审程序可以 (•̀ᴗ•́) 实时自动纠正论文结论。 来源：科研机构的高效实验工具

2. Claude Code 或将新增提示音 ​

Claude Code 或将新增提示音。 开发者等待 终端运行 程序时易分星。 此时系统 响铃提醒 🔔 会很实用。 我们能从 社区用户反馈建议 里找到共鸣。 这种小改动 (シ_ _)シ 能让 用户体验 大不同。 来源：社区用户反馈建议

前沿研究 ​

1. 上海交大提出图像编辑模型 ​

上海交大提出图像编辑模型。 高校团队发表了 精准图像编辑控制模型 论文。传统点拖拽修图 🤦‍♂️ 容易造成画面严重变形。用户可以用画笔自由选择多个 目标区域。双向注意力机制让 ✧(◕‿◕)✧ 画面更加真实。 来源：精准图像编辑控制模型

2. 英伟达发布芯片设计新框架 ​

英伟达发布芯片设计新框架。 芯片巨头推出了 自动化硬件设计新框架 成果。团队采用 工作流演化 🛠️ 实现了无感设计。智能代理在测试中 (°Д°) 达到了满分完成率。研究人员称硬件设计问题目前仍未完全解决。 来源：自动化硬件设计新框架

3. 大模型记忆管理技术获突破 ​

大模型记忆管理技术获突破。 团队开发出 基础大模型记忆优化框架 技术。这种方法能将 记忆管理 训练为基础技能。优化方案让 🚀 基础智能体性能大幅提升。开源模型由此可以 😉 媲美顶尖商业模型。 来源：基础大模型记忆优化框架

4. 我国研制全球首款基于可控存内计算的忆阻器神经动力学芯片 ​

北京大学集成电路学院联合中科院上海微系统所，发布全球首款基于可控存内计算的忆阻器神经动力学芯片，首次将单步运算时延压缩至 2.12 毫秒。芯片采用 40 纳米工艺，存内计算阵列与外围电路总面积 0.28 平方毫米，运行频率 50 MHz，单步积分仅需 9 级流水。在脑皮层重建等任务中较当前 GPU 提速 50 至 478 倍，突破神经动力学实时计算瓶颈。相关成果 7 月 3 日发表于《科学》。 来源：IT 之家（RSS）

5. NVIDIA 联合多所大学提出 ASPIRE：自我改进机器人框架，零样本成功率最高提升 77 分 ​

NVIDIA 联合密歇根大学、UIUC、UC Berkeley 等提出 ASPIRE，一个持续学习机器人框架。它通过协调器-执行器架构、闭环执行引擎、技能库和进化搜索，编写并优化机器人控制程序。编程智能体使用 Claude Code（Claude Opus 4.6，1M token 上下文窗口）。在 LIBERO-Pro 上最高比最强基线提升 77 分；Robosuite 双手交接成功率从 20% 提升至 92%；BEHAVIOR-1K 收音机拾取任务从 56% 提升至 88%。利用 LIBERO-90 积累的技能，ASPIRE 在零样本条件下对 LIBERO-Pro Long 任务达到约 31% 成功率，此前方法饱和在 4% 附近… 来源：MarkTechPost（RSS）
