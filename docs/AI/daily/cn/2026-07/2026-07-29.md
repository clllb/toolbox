## 模型与产品更新

### 1. Claude 成功破解传统密码漏洞

Anthropic 披露 **Claude Mythos** 预览模型在加密研究中发现算法弱点，目标包括抗量子算法 HAWK 与七轮 AES 变体。这个案例的重点不是“模型能直接攻破现网系统”，而是 AI 已经能在数学安全分析里帮助研究者缩短探索路径；官方也强调当前现网系统仍保持稳定，风险更偏向未来算法设计与审计流程 🔒。来源：[研究全文](https://www.anthropic.com/research/discovering-cryptographic-weaknesses)

### 2. OlmoEarth 行星级地理平台发布

Ai2 发布 **OlmoEarth** 地理推理基础设施，用 10TB 卫星数据构建行星级地理平台，并通过 994 块 GPU 并行处理大规模算图。它把推理时长从 4737 小时 压到 30.5 小时，说明地理 AI 的瓶颈正在从“有没有模型”转向“能否把数据、算力和推理链条接稳” 🌍。来源：[平台架构说明](https://huggingface.co/blog/allenai/olmoearth-infrastructure)

### 3. 智能体全面重塑科学计算流程

OpenAI 总结了编码智能体在科学计算中的八项落地案例，重点覆盖基因组工具开发、实验脚本维护和专家审查协作。报告强调智能体能显著降低维护开销，但上线前仍需要领域专家做最后审查；这类工作流更像科研团队的“执行层增强”，不是替代科学判断 🧪。来源：[智能科研报告](https://openai.com/index/scientific-computing-agentic-ai/)

### 4. Microsoft 发布 MAI-Cyber-1-Flash

Microsoft AI 发布 **MAI-Cyber-1-Flash**，这是一款 137B 总参数、5B 活跃参数、256k 上下文窗口的稀疏 MoE 网络安全模型，也是 MAI-Code-1-Flash 的微调版本。它驱动 MDASH 在 CyberGym 上达到 95.95%，显示安全专用小活跃参数模型正在成为高性价比路线 ⚙️。来源：[模型报道](https://www.marktechpost.com/2026/07/28/microsoft-ai-releases-mai-cyber-1-flash-a-5b-active-parameter-cyber-model-that-pushes-mdash-to-95-95-on-cybergym)

### 5. FeyNoBg 发布开源自动背景去除模型

Feyn Labs 推出 **FeyNoBg**，面向自动背景去除任务，并在八个基准中的四项拿到最佳 S-measure 分数。模型基于 BiRefNet 架构，参数量从 222M 扩展到 263M，同时开源训练库 NoBg，适合图像编辑、商品图处理和内容生产流水线接入 ✨。来源：[发布说明](https://usefeyn.com/blog/feynobg)

### 6. OpenAI 推出两款新转录模型 API

OpenAI API 新增 **GPT-Live-Transcribe** 与 **GPT-Transcribe**：前者面向低延迟实时转录，后者面向已完成音频和批量工作负载。两款模型都强化了上下文理解，对短句、数字、专业术语、口音与背景噪声场景更友好，语音产品的基础件继续变厚 (^\_^)v。来源：[开发者公告](https://x.com/OpenAIDevs/status/2082201169443905798)

### 7. Gemini API Managed Agents 默认升级为 3.6 Flash

Google DeepMind 将 **Gemini API Managed Agents** 默认模型升级到 Gemini 3.6 Flash，并允许显式选择 3.5 Flash 或 3.5 Flash-Lite。新增环境钩子可在沙箱工具调用前后执行脚本，用于安全审查、格式化和工作流检查；免费套餐、预算控制与 cron 触发也降低了试用门槛 ☁️。来源：[Google 开发者更新](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks)

### 8. 火山引擎上线豆包搜索服务

火山引擎上线 **豆包搜索服务**，为 AI Agent 提供跨语言、多模态、多垂类的联网信息查询。它结合全域互联网、行业知识和字节跳动内容资源，并从站点与创作者维度建立权威分级体系；接入形态覆盖 API、Skill、MCP，每月 500 次免费额度适合开发者快速验证 🔎。来源：[产品公告](https://mp.weixin.qq.com/s/1nZqQHYqclsIF6__WLscgA)

### 9. Cursor 在印度推出 Cursor Start 计划

Cursor 面向印度开发者推出 **Cursor Start**，月费 ₹649（含税），支持 UPI 支付，并提供 Grok 4.5、Composer、更多 agent 请求、常驻云端 agent 与 iOS 端能力。印度已是 Cursor 第三大市场，用户超过 300 万，人均 agent 请求量全球最高，这让区域定价开始成为 AI 编程工具竞争的一部分 📈。来源：[Cursor 公告](https://cursor.com/blog/cursor-start-india)

### 10. Grok 接入工作区

## 前沿研究

### 1. 冻结百亿大模型逆袭前沿旗舰

研究提出“验证记忆”机制，在冻结百亿参数模型的情况下实现零令牌复用。它在九类推理任务中拿到 180 满分，记忆检索仅需 1.4 微秒，并让六百万级超长上下文能在单卡运行；如果复现稳定，长上下文成本结构会被重新计算 🧠。来源：[论文页面](https://huggingface.co/papers/2607.23806)

### 2. Kimi K3 发布并开源全部权重

月之暗面推出 **Kimi K3**，2.8T 规模 MoE 模型，支持原生视觉与百万上下文，并提出 KDA 优化长序列信息流。权重与技术报告开放后，核心看点不只是“参数更大”，而是开源权重能否支撑独立部署、复现实验和下游编码工作流 (๑•̀ㅂ•́)و✧。来源：[论文页面](https://huggingface.co/papers/2607.24653)

### 3. ClinFusion 开创视觉中心医疗大模型

**ClinFusion** 采用视觉中心路线统一二维与三维医学影像，在医疗多模态任务上刷新 20 项 行业基准。盲测报告获得放射科专家认可，说明医学多模态模型的价值正在从“能看图”推进到“能支撑临床工作流判断前的结构化辅助” 🩻。来源：[论文页面](https://huggingface.co/papers/2607.24743)

### 4. StateAct 用程序状态驱动电脑智能体

**StateAct** 主张电脑智能体应优先读取程序状态，而不是只依赖屏幕像素。主代理直接通过代码读取文件与 DOM，复杂操作再分发给 GUI 子代理，任务成功率提升到 26.9% 且开销下降；这条路线对浏览器自动化、IDE 操作和本地应用 agent 都有参考价值 🛠️。来源：[论文页面](https://huggingface.co/papers/2607.22798)

![AI资讯：StateAct论文封面展示程序状态驱动框架](/ai/daily/2026-07-29/news_01kyntvfr8enebmfx783ctn2ww.avif)

### 5. MAPD 打通闭源与开源蒸馏鸿沟

**MAPD** 用多智能体协议蒸馏闭源教师模型的复杂推理过程，并通过 JSON 协议承载中间推理轨迹。实验里 Qwen3-1.7B 达到 39.4% 成功率，Qwen3-4B 提升到 44.4%，说明更结构化的教师信号可能比单纯答案蒸馏更有效 🔎。来源：[论文页面](https://huggingface.co/papers/2607.24280)

![AI资讯：多智能体协议蒸馏论文缩略图](/ai/daily/2026-07-29/news_01kyntvj9eenebmfx9gxtvgx6r.avif)

### 6. DecoupleMix 重塑多模态数据配方

**DecoupleMix** 把多模态数据混配拆成跨类配比和类内样本选择两个子问题：前者用单变量搜索，后者用凸优化保障多样性。论文展示了 80B 训练效果，提示训练数据配方可能继续从经验调参转向可优化对象 ⚙️。来源：[论文页面](https://huggingface.co/papers/2607.24516)

![AI资讯：DecoupleMix论文展示数据配方优化流程](/ai/daily/2026-07-29/news_01kyntvmzmenebmfxqbzwnf0vf.avif)

### 7. LLM 伪科学评测揭示配置漏洞

一项伪科学评测发现，同一模型在 API 与网页端可能给出明显不同的判断，Grok Fast 一度给出 70-75 的偏高分数，随后疑似通过静默补丁调整表现。论文呼吁建立“认知问责”，把评测配置、部署版本和模型行为变更纳入记录，避免把网页端偶然结果误读成稳定能力 ⚠️。来源：[论文](https://arxiv.org/abs/2607.22513)

### 8. TRACE-Router 实现任务级智能体路由

**TRACE-Router** 把智能体路由从“按模型能力静态分配”推进到任务级调度，使用终局奖励同时衡量准确率和延迟。在 Terminal-Bench 中，它将延迟降低 36%，对多模型 agent 系统的成本控制很直接：不是每个任务都需要最强模型出手 🧭。来源：[论文](https://arxiv.org/abs/2607.22465)

### 9. Kimi Linear 提出高效注意力架构

月之暗面发布 **Kimi Linear**，一种混合线性注意力架构，在短上下文、长上下文和强化学习场景下全面对比全注意力机制。其 3B 激活参数模型在评估中优于全 MLA，KV cache 最多降低 75%，在 1M 上下文下最高实现 6 倍解码吞吐量 🧠。来源：[论文](https://arxiv.org/abs/2510.26692)

### 10. Apple 为 Siri Expressive Voices 推出内存高效音频架构

Apple 研究团队为 **Siri Expressive Voices** 推出内存高效音频合成架构，detokenizer 在 AMX 上约 10ms/步，峰值内存约 21MB。相比此前设备端系统，Mean Opinion Score 整体提升 +0.28（4.15 vs. 3.87），对话语音提升 +0.42（4.24 vs. 3.82），端侧语音体验继续补短板 🎧。来源：[Apple 研究](https://machinelearning.apple.com/research/audio-synthesis-diffusion-transformers)
