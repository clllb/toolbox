## 模型与产品更新

### 1. Microsoft 将 Copilot 打造成智能超级应用

Microsoft 计划在年内把 **Copilot** 推向更统一的多端助手形态，重点整合聊天、代码、办公和自动化能力。The Verge 报道称，新体验会把移动端、桌面端和生产力场景打通，目标是让助手不只回答问题，还能持续执行跨应用任务；这意味着 Copilot 正从单点功能走向工作流入口 🚀。来源：[The Verge 报道](https://www.theverge.com/tech/972927/microsoft-copilot-super-app-confirmed)

### 2. NVIDIA 发布 Cosmos-Dreams 闭环神经模拟器

NVIDIA 在 SIGGRAPH 2026 期间展示 **Cosmos-Dreams**，这是一组面向物理 AI 的闭环模拟器，可从单帧生成自动驾驶场景世界，并用于验证模型准确性或生成难以在真实世界采集的训练场景。它的价值在于把“世界模型”接到机器人与自动驾驶训练循环里，让仿真不只是展示画面，而是能反哺策略开发 🧠。来源：[NVIDIA 博客](https://blogs.nvidia.com/blog/siggraph-news-2026/)

### 3. OpenAI 发布 GPT-5.6 模型家族

OpenAI 发布 **GPT-5.6** 系列，包含 Sol、Terra 与 Luna 三个层级。官方介绍称，旗舰款 Sol 在最大推理设置下于 Artificial Analysis Coding Agent Index 超越 Claude Fable 5，成本不到后者一半；Terra 智能接近 GPT-5.5 但价格减半，Luna 定价比 Sol 低 80%，产品线开始更明确地区分前沿能力、成本和吞吐效率 ⚙️。来源：[OpenAI 公告](https://openai.com/index/gpt-5-6-frontier-intelligence-efficiency)

### 4. Google DeepMind 推出 Lyria 3.5

Google DeepMind 在 Flow Music 中推出 **Lyria 3.5**，强化音乐性、歌词、人声表现力和创作控制。新模型更强调旋律结构、歌词提示遵循和输出节奏控制，对音乐生成产品来说，重点已经从“能生成声音”推进到“可控、可编辑、可用于创作流程” 🎬。来源：[Google DeepMind 博客](https://deepmind.google/blog/were-launching-lyria-35-in-google-flow-music-with-advances-across-musicality-lyrics-vocals-and-creative-control)

### 5. Replit Design 发布 AI 设计工作流

Replit 发布 **Replit Design**，把从想法到界面设计的过程接入 Ambient Intelligence，并支持 Claude、GPT-5、Gemini、Kimi、GLM 等模型参与设计生成。它的定位不是单独导出一张稿，而是让设计资产继续留在 Replit 工程环境里，减少从设计到实现的交接损耗 ✨。来源：[Replit 博客](https://replit.com/blog/introducing-replit-design)

### 6. Deltafin 在 M1 Max 上运行 2.8T 参数 Kimi K3

Deltafin 项目在 64GB **M1 Max** 上运行 2.8T 参数 MoE 模型 Kimi K3，中位推理速度为 0.0687 token/s，即约 14.6 秒/token。完整安装约需 1.7TB 本地磁盘，流式模式只需 215GB 但速度会降到 3 分钟以上/token；这不是消费级可用速度，却给超大 MoE 本地推理提供了可复现边界 ( •̀ ω •́ )。来源：[GitHub 项目](https://github.com/gavamedia/deltafin)

### 7. 开源引擎让 Gemma 4 26B 在 M 系列 Mac 上以 2GB 内存运行

开源项目 **turbo-fieldfare** 宣称可让 Gemma 4 26B 在任意 M 系列 Mac 上运行，并把内存需求压到 2GB。它更像一次工程压缩实验：如果稳定复现，本地模型部署的硬件门槛会继续下降，开发者可以在低成本设备上测试更大的模型能力 🛠️。来源：[GitHub 项目](https://github.com/drumih/turbo-fieldfare)

### 8. 腾讯混元开源 AngelSpec 投机解码框架

腾讯混元开源端到端投机解码框架 **AngelSpec**，覆盖训练与部署流程。在 Hy3-A21B 模型上，DFly 方案相比自回归解码实现 1.98-2.40 倍端到端加速，吞吐量比 DFlash 高 10.5-11.8%；训练代码和 Hy3-A21B MTP/DFly 草稿模型权重也已开放，适合关注推理效率的团队跟进 ⚡️。来源：[腾讯混元公告](https://x.com/TencentHunyuan/status/2082447023626944936)

### 9. OpenAI 向 10 万学术研究者开放高级模型

OpenAI 面向 10 万名学术研究者免费提供 ChatGPT 高级模型访问权限，目标是降低科研团队使用前沿模型的门槛。对研究机构来说，关键不只是免费额度，而是能否把模型访问、协作审查和实验记录纳入长期科研流程 🧪。来源：[OpenAI 公告](https://openai.com/index/chatgpt-for-academic-researchers)

### 10. LangChain Deep Agents v0.7 降低基础输入 token

LangChain 发布 **Deep Agents v0.7**，通过简化 base harness，在保持可比性能的同时将基础输入 token 减少 65%。这类优化直接影响 agent 的单位任务成本，也说明框架层“少带上下文、少浪费 token”正在变成生产级智能体的核心指标 ☁️。来源：[LangChain 博客](https://www.langchain.com/blog/deep-agents-v0-7)

### 11. Hint 推出面向房主的 AI 家居助手

Martha Stewart 联合创办的 **Hint** 推出 AI 家居管理助手，面向维护计划、能源管理、土壤和空气质量、保险文件、合同和发票查询等场景。TechCrunch 报道称，该应用可基于房屋地址和用户上传资料建立家庭档案，并通过内置助手回答具体维护问题；消费级 AI 正继续向“具体资产管理”扩展 🏠。来源：[TechCrunch 报道](https://techcrunch.com/2026/07/29/hint-a-new-ai-startup-co-founded-by-martha-stewart-offers-an-ai-assistant-for-homeowners/)

## 前沿研究

### 1. 轻量视觉语言动作模型提升机器人控制效率

研究提出 0.9B 规模的轻量视觉语言动作模型，用较小参数量处理机器人控制任务。它的重点是通过微调和动作生成设计提升控制效率，而不是单纯堆大模型规模；如果这种路线持续成立，机器人端侧控制会更容易获得低延迟、低成本方案 🧠。来源：[论文页面](https://arxiv.org/abs/2607.25487)

### 2. 动态对抗评测缓解大模型数据污染

新论文提出面向大模型对齐的动态评测框架，用对抗博弈方式让多个模型轮流生成和回答问题。相比固定静态测试集，这类系统更难被训练数据污染，也更接近真实部署中的持续攻防；它提醒团队评估模型时要看更新机制，而不是只看一次性榜单 (๑•̀ㅂ•́)و✧。来源：[论文页面](https://arxiv.org/abs/2607.24780)

### 3. 通用视频世界模型支持相机可控漫游

研究者提出支持相机可控漫游的视频世界模型，通过稀疏注意力生成可探索的新视角影像。它把视频生成从单段剪辑推进到“可控制地进入场景”，对游戏、仿真、机器人数据和虚拟拍摄都有潜在价值 🎮。来源：[Hugging Face 论文页](https://huggingface.co/papers/2607.26037)

### 4. 透视视角自博弈驾驶模拟器完成验证

自动驾驶研究团队构建透视视角自博弈仿真环境，并在单卡上维持高渲染率。实验成功训练出驾驶端策略，并展示零样本迁移能力；这说明自动驾驶仿真正在把视觉生成、策略学习和闭环评估更紧密地绑在一起 🚗。来源：[论文页面](https://arxiv.org/abs/2607.26005)

### 5. 真实世界网络渗透智能体评测发布

研究提出网络安全渗透测试协议，用真实世界任务评估智能体的漏洞自动发现率。相比在玩具环境里跑分，这类评测更关注工具调用、信息收集和攻击路径规划的实际表现；随着智能体能力增强，安全评测本身也必须更贴近真实边界 ⚠️。来源：[论文页面](https://arxiv.org/abs/2605.10834)

### 6. Miles 在 Blackwell 上验证低精度强化学习

Miles 团队在 Blackwell 架构上实现端到端 **MXFP8** 与逐 token **NVFP4** 强化学习方案，并在 8x B200 上对 Qwen3-30B-A3B 做消融实验。结果显示 BF16 与五种低精度配置的原始奖励曲线高度重合，同时 MXFP8 和 NVFP4 减少了推理时间；训练后期的低精度路线正在从推理优化扩展到 RL 管线 ⚙️。来源：[LMSYS 博客](https://www.lmsys.org/blog/2026-07-29-mxfp8-nvfp4-rl)

### 7. K-Search 将 CUDA 内核优化迁移到 Apple Silicon MLX

伯克利 Sky Lab 基于 **K-Search** 开发 CUDA 到 MLX 的结构化翻译层，让 AI 驱动的内核搜索把 NVIDIA GPU 上积累的优化经验迁移到 Apple Silicon。对本地 AI 开发来说，这类工具有机会缩短“会写模型代码”和“能写高性能内核”之间的距离 🛠️。来源：[BAIR 博客](http://bair.berkeley.edu/blog/2026/07/29/cuda-to-mlx-k-search)

## 开源与开发者工具

### 1. OpenWork 开源协作开发环境获得 🌟17.9k

**OpenWork** 是一个免费开源的协作开发环境替代品，主打自动合并代码仓库和解析复杂工程结构。它适合多人协作、长分支合并和 agent 辅助开发场景，核心价值是把代码理解、变更协调和合并流程做成可复用工具链 🛠️。来源：[GitHub 项目](https://github.com/different-ai/openwork)

### 2. FlashKDA 优化超长上下文推理内核 🌟1k

Moonshot AI 开源 **FlashKDA**，面向超长文本计算和推理场景优化内核。项目当前接近 1k 星，说明长上下文模型发布之后，真正的工程竞争会落到 KV、注意力和推理吞吐这些底层环节 ☁️。来源：[GitHub 项目](https://github.com/MoonshotAI/FlashKDA)

### 3. Airi 自托管伴侣项目走红 🌟45.4k

**Airi** 主打自托管伴侣和实时语音交互，支持跨端部署，并可连接 Minecraft 与 Factorio 等场景。它的热度说明“本地可控、角色持续、能接入应用”的伴侣型 agent 仍有强需求，但这类项目也需要认真处理隐私、身份和长期记忆边界 ✨。来源：[GitHub 项目](https://github.com/moeru-ai/airi)

### 4. jcode 主打省内存运行评测 🌟13.4k

**jcode** 聚焦低内存运行和代码场景评测，仓库热度仍在上升。对开发者来说，这类项目的价值不只是跑出榜单，而是提供能在资源受限机器上复验模型表现的工具，帮助判断本地 agent 是否真的可用 🧠。来源：[GitHub 项目](https://github.com/1jehuang/jcode)

### 5. 阿里开源代码评审工具 🌟16k

阿里开源 **open-code-review**，采用混合架构做代码评审，并强调行级评论、空指针和注入等规则检查。AI code review 正在从“给一段总结”走向具体行、具体风险和可执行修复建议，适合接入 CI 或团队日常审查流程 🔍。来源：[GitHub 项目](https://github.com/alibaba/open-code-review)

### 6. Perplexity 开源 Agent 安全套件 Numbat

Perplexity 发布 **Numbat**，定位为跨 macOS、Linux 和 Windows 客户端端点的开源 agent 安全套件，用于检测、阻止和调查高风险 AI agent 行为。随着桌面 agent 获得更多文件、浏览器和应用权限，端点侧检测会成为部署前必须补上的安全层 🔒。来源：[Perplexity Research](https://research.perplexity.ai/articles/securing-agents-across-perplexity%E2%80%99s-client-endpoints-with-numbat)
