原文链接：你觉得什么叫做生活？

前言 ​

新创建了一个专栏-生活，这个专栏咱们不讲技术，就给大家讲讲我的生活，讲讲什么 TMD 叫 TMD 生活。玩的就是真实，咱不整虚的。

一.总结 2022 ​

1.从校园到社会 ​

看这篇文章的开始可以先问问自己你觉得什么叫做生活？ 我很喜欢一句话：生活很简单，就是好好的活着。我心里的生活就是这样，简简单单的活，做好自己该做的，做自己喜欢的。不要被别人所干扰。接下来我讲讲我自己的生活。

1.1 校园生活 ​

 我是 22 届毕业的，最终选择了去奇安信工作，我是 java 服务端开发工程师，其实就是搞平台的。其实挺想讲讲我的校园生活，我是毕业于黑龙江科技大学，计算机与信息工程学院，我来的时候还是二本，后来产房传来喜讯，tmd 升了，变成一本了，这也是我没想到的，还捡了个便宜。  我是个很喜欢玩，喜欢社交的一个人，大学参加了各种活动，各个领域都接触了，吉他、相声、主持、跳舞、演各种小品等等，参加各种社团，参加学生会。大一时候爽上天了，唯独没人告诉我要好好学习，保研才是最牛逼的，听我一句劝好好学习，保研才是最牛逼 。  最终在大二的时候我选择去吉他社担任社长，这才是我最喜欢的地方，过去了两年我还时常挂念，吉他社现在做的好不好，有时候还会去问问在校的朋友。真的非常喜欢，我愿意为吉他社付出我的全部。我把大二一年的时间全部投入到吉他社中，如何带领团队，如何把吉他社做的更好，如何能让大家开心。付出也是有收获的，我那届是到现在以来报名人数最多的一届，我记得好像是三百多人。但是中途也出现的各种问题，决策方面的，考虑的不周到等，这些都是促进我成长的一部分。但是也有遗憾，正常是每届都要办一场音乐节，但是我们那届赶上疫情没法办，只办了一些小活动。

给大家展示一些图片，我们社团的团徽。

我最喜欢的一个，也算是团徽，也是乐队的队徽。 乐队的夏天是我唯一看完的综艺。
在广场办的迎新生活动，拍鼓的是我，哈哈哈

1.2 走向社会 ​

 到了大三，才明白到大三下学期就必须要找实习了，大三就开始学习 java，整体都是在 b 站自学的，有问题先百度。实在不会的再去找老师，我也遇到了个好老师愿意为我解答我的问题。学了半年吧，就开始找实习。我总体经历了小厂-中厂-大厂的过程，一直都在北京现在已经是第三次来北京了。  在大三下学期的时候，投了春招的实习，在暑假的时候去了一家做家政的小厂，给的还挺多我记得好像是 270 一天。整体技术还算新，SpringCloudAlibaba 那一套，后来我走了公司倒闭了，没拖欠我工资，还是挺幸运的。  到了大四上学期，那时候感觉自己学的一般就实习和招聘一起投，其实这里就是一个错误，正常就不应该去找实习，一心一意走秋招，现在的实习转正率也很低，因为没有 hc，也就是没有坑了。但是秋招也找到了一个还不错的公司，作为我秋招保底，签了 offer。也找到了一家游戏公司的实习，我决定去游戏公司实习，如果不好在去秋招保底，或者在冲一波大四下学期的春招。到了游戏公司发现是做 JavaScript 转 Java 的组，就我和带我的哥两个 Java，而且用的技术是真的老，还在用 svn，我还需要学习 JavaScript，这里也是因为我面试时候没问清楚太着急了，我干了两个月果断跑路。我决定冲一波春招。  大四下学期，我准好了，然后发现还是投晚了，错过了提前批，所以看到这的小伙伴会发现，没有一个引路人要踩多少的坑，都是我摸爬滚打过来的。春招的岗位是真的少，投了几百份，面试上的不到十个吧。很幸运的是我第一批就过了现在的公司，而且给到了满意的薪资。奇安信不能算是完全的互联网公司，但是在网安这条新赛道是龙头，也可以算是大厂吧。整体技术就不讲了，其实我写的博客就是现在用到的技术，都是当下很新很前沿的技术。

1.3 我的生活 ​

 我很喜欢喝酒，来到北京，每周都会和朋友出去喝酒，喝个几瓶微醺，觉得很舒服。自己在家买了一箱啤酒-天涯，东北的小伙伴应该都知道。没事就喝点，最近刚喝完一箱，要是有节日就会多喝点，比如今年跨年时候，但是从来不会说喝吐，适可而止就是最好的。大一时候家里出现一些重大变故，我的大学四年都是靠的贷款，一共三万二的助学贷款，我现在每月还几千慢慢还。不要想的太多，不要给自己太多的压力，该花花、该玩玩、该工作工作。现在是晚上凌晨12.40，我必须今天写完，明天早上发，要不就要回家过年了。哈哈哈  我每天的时间安排是很规律的，每天早晨七点半起，练半个小时的金刚经，洗漱八点半出门，走路去公司九点之前到还能买个包子吃。每天晚上八点半下班，坐两站公交九点到家，休息一会，九点半练长寿功，晚上在抽出一个小时时间学习天纪。  这就是我的生活，一个普通上班族的生活，如何你相信我，如果你也喜欢喝点，来北京找我，我请你喝酒。

2.写博客的初衷 ​

 我很早就了解这个平台，在大二时候吧。那时候零零散散也写过一些，但是真正的开始就是 22 年的十月开始，我刚来到北京上班，学了很多新东西，那时候正好有十月更文活动，把学到的技术作为总结，自己可以随时看，这就是我的初衷。我决定把这个事情做下去，一直坚持到现在，在一月份的时候破了万粉，正好 80 天。还是有非常多的技巧的，等我创建社区，在创建我自己的群的时候，都会告诉给大家。等一波二月份的社区活动，到时候我会准备非常多的礼物。

3.收获与提升 ​

 最重要还是认识了很多朋友吧，这里我最最最感谢的就是几分醉意.我俩相互扶持吧，从1024时候认识，一直到现在帮助了我很多，是一个非常优秀的老弟。和他聊天都快比和我对象聊的多，哈哈哈。在之后的社区创建，带领新人这些事，我们会一起把这个事做好。在写博客的时候，你会发现这个问题你到底会不会，到底有没有研究明白，而且还有人帮你纠错，我觉得一个人只有不断的改正错误，提升才是最快的。而且获得了太多的礼品，这里就不展示了，帆布袋我都有十多个了，还有五个包，非常感谢官方，老板大气。

二.展望 2023 ​

1.博客方面 ​

 破万粉算是我第一个目标，对于 2023 还是有非常多的期待，这里也立个 flag 吧。

  • 2023可以突破5w粉丝数
  • 创建一个5k人以上的社区
  • 社区中举办8次以上的活动

2.工作方面 ​

 工作方面，现在大环境不好，卷一卷吧。希望公司不要裁我，我能提升一个级别，这个愿望就谢天谢地了。希望所有人都不要被裁。

三.对于即将要告别校园的同学的忠告 ​

且行且珍惜 ​

 上了班之后会发现和朋友同学一年只能见一回，在校园的生活都变成了回忆。离父母更远了，只有过年才能回家。永远不要留下遗憾，有什么想做的，有什么想说的，都在还未结束的校园生活中实现吧。为了你爱的人和爱你的人，简单的去生活，简单的活下去。

**总结：希望每个人都可以不忘初心。
