产品与功能更新 ​

  1. Claude 百万 token 上下文正式上线。 Anthropic 宣布 🎉 Opus 4.6 和 Sonnet 4.6 全面支持100 万 token上下文窗口。不再收取长文本溢价，百万上下文统一定价全面开放（AI 资讯）令开发者欢呼。单次请求支持600 张图片或 PDF，多模态能力 💪 提升六倍。MRCR v2 测试中 Opus 4.6 拿下78.3%高分，长文本检索能力断层领先。Claude Code 年化收入超25 亿美元，OpenAI Codex 仍在追赶。

  2. 360 发布安全龙虾系列产品。 360 集团在京推出 🦞「360 安全龙虾」客户端及硬件终端，国内首个安全模式 OpenClaw 产品发布（AI 资讯）引发关注。原本需6 小时部署的环境被压缩到10 分钟一键安装 ⚡。系统已接入16 家主流大模型，内置超 100 个高频技能。「360 龙虾卫士」通过沙箱隔离和以模治模机制拦截提示词注入等攻击。入门套餐定价169 元，Windows 客户端已开放下载。

  3. 阿里 Qwen3-ASR 语音转录模型发布。 通义千问一口气 🎙️ 推出三款语音识别模型，Qwen3-ASR 覆盖 52 种语言开源发布（AI 资讯）正面挑战 Whisper。旗舰版1.7B支持 30 种语言加 22 种中文方言。轻量版0.6B一秒能转写 🚀 2000 秒音频，延迟最低 92 毫秒。歌曲转写中文歌词错误率仅13.91%，带 BGM 识别实用性强。采用Apache 2.0协议完全开源可商用。

  4. 智诊科技发布医疗智能体平台 WiseClaw。 基于 OpenClaw 架构，全球首个医疗 Agent OS 平台正式上线（AI 资讯）瞄准千亿医疗市场。平台支持 🏥 多智能体协作拆解复杂医疗流程。每条建议都附带医学证据链，可追溯到指南条款。内置权限管理和脱敏机制 🔒 满足医疗合规要求。弗若斯特沙利文预测中国 AI 医疗市场将达3157 亿元。

前沿研究 ​

  1. 上海 AI Lab 提出知识推理解耦框架 DRIFT。 小模型负责 📖「读书」，大模型专注「思考」，DRIFT 实现知识与推理高效分离（AI 资讯）引发学界关注。3B 知识模型加 7B 推理模型组合下，32 倍压缩后性能接近甚至 ✨ 超过全文输入。推理延迟在各上下文长度下保持最低水平。未经安全训练的情况下，该架构在多项安全基准上 🛡️ 鲁棒性显著提升。研究团队还将该思路拓展到蛋白质理解任务（AI 资讯）中验证。

行业展望与社会影响 ​

  1. 2026 年 3 月科技裁员已达 4.5 万人。 HN 社区围绕三月科技裁员数据激烈讨论（AI 资讯），争论这是否算新一轮裁员潮。Meta 计划再裁约 😨 20%员工，同时 2026 年预计 AI 支出高达1350 亿美元。部分评论认为 AI 只是被拿来当裁员借口 (╥﹏╥)，疫情期过度招聘才是主因。Google 今年 AI 资本支出预计达1700-1800 亿美元，企业把钱从人头转向数据中心。失业者反映被招聘方 👻 ghosting 情况加剧，求职市场持续恶化。

  2. Meta 自研大模型 Avocado 遭延期。 据纽约时报等多家媒体报道，Meta 新一代基础模型因性能不达标推迟发布（AI 资讯）。内测中 Avocado 仍 😅 落后于Gemini 3.0。Meta 内部甚至讨论过临时授权 Google 模型来支撑自家产品。扎克伯格和 Alexandr Wang 更倾向 🔐 闭源路线，这与 Llama 系列开源策略形成反转。下一代模型命名延续水果系列：Avocado → Mango → Watermelon。

  3. AI 未简化软件工程，只放大了好坏差距。 HN 热帖指出 AI 是行为的 🔊 放大器，优秀和糟糕的工程实践同时被规模化（AI 资讯）。Opus 4.5/4.6 在精细约束上出现漂移，LLM 生成代码已 💥 引发线上中断事故。初级开发者过度依赖 AI 导致基本功退化，技术债持续累积。评论者担忧公司以提效为由裁员 (；′⌒`)，中产岗位面临收缩风险。AI 在探索原型阶段效率极高，但生产化仍需人工审查。

  4. Claude Code 二进制暴露静默 A/B 测试。 开发者在本地二进制文件中发现Anthropic 对核心功能做静默分组实验（AI 资讯），引发可复现性争议。有人以 Photoshop 悄悄改颜色类比 😤 来说明问题严重性。服务条款第 6.b 节允许厂商随时更改订阅内容，第 3.3 节禁止反编译。部分用户因此转向 🏃 开源或自托管替代方案。评论区也有人认为 SaaS 做 A/B 测试本就是行业常态。

  5. OnlyFans 时薪 2 美元外包聊天员引发伦理争议。 BBC 报道揭露平台背后低薪外包劳动与 AI 替代真相（AI 资讯），菲律宾聊天员仅拿销售额约5%提成。塞浦路斯等地已从人工过渡到 🤖 AI 或混合站点替代真人。用户买的是「体验」而非真人互动，拟社会关系概念被反复提及。禁令派与反对派激烈交锋 ⚖️ ，历史证明禁令只会推动行业地下化。成人行业正快速走向自动化，从业者面临被 AI彻底替代的风险。

  6. 创始人营销：AI 放大噪音群发效力下降。 HN 讨论指出 AI 生成内容大幅增加了 📢 平台噪音，群发渠道清单的边际效果显著降低（AI 资讯）。冷发到 50 个论坛常带来短期流量但 🫥 零留存。评论者建议用 Claude Code 对发布站点打分生成优先级清单。长期在目标社区建立信誉的策略更被推崇。是否早期投入 SEO 应根据产品类型差异化决策。

开源 TOP 项目 ​

  1. OpenViking：字节开源智能体上下文数据库。 火山引擎推出的开源上下文管理库（AI 资讯） ⭐10.5k，专门为 OpenClaw 等智能体设计。采用 📂 文件系统范式统一管理记忆、资源和技能。支持层级化上下文分发和自我进化能力。日增 Star 达 🔥 1610 颗，Python 语言编写。

  2. Lightpanda：专为 AI 设计的无头浏览器。 用 Zig 语言编写的超轻量无头浏览器（AI 资讯） ⭐17.1k，日增 🚀 2069 颗Star。专为智能体网页抓取和自动化任务打造。简化配置流程 ⚡ 让开发者快速集成。

  3. OpenRAG：一站式检索增强生成平台。 Langflow 团队发布的全栈 RAG 解决方案（AI 资讯） ⭐2.7k，深度整合 🔍 Docling文档解析和Opensearch检索引擎。开发者可快速构建企业级检索增强应用。

  4. InsForge：智能体全栈应用后端框架。 专为 Agent 开发打造的全栈后端框架（AI 资讯） ⭐4.2k，TypeScript 编写。让智能体拥有 🛠️ 一站式交付全栈应用的能力。

  5. autoresearch：进化数据库增强版自动研究。 基于 Karpathy 自动研究项目，社区开发者集成进化数据库替代原始日志系统（AI 资讯）。灵感来自 DeepMind 的 🧬 AlphaEvolve进化算法框架。可自主发现大搜索空间中的最优解。

社媒分享 ​

  1. CC 用户和龙虾用户的 I 人 E 人之分。 博主@Orange AI 观察到 🍜 聚餐中途两人离席回去和 Claude Code 干活，CC 用户宅家聊天龙虾用户外出社交（AI 资讯）形成鲜明对比。CC 没有聚会全是龙虾聚会 (≧▽≦) 。这就是新时代的I 人和 E 人。

  2. OpenClaw 全指令速查手册分享。 博主@meng shao 帮医生老同学装龙虾后 📋 整理了一份完整手册，涵盖安装配置交互记忆安全全流程（AI 资讯）。工作区用文件驱动行为，不靠隐藏 prompt。排障万能公式 🔧 openclaw doctor --deep --yes解决 80%问题。

  3. xAI 前员工大爆料被一条推特逼走。 前员工 De Kraker 💣 引用马斯克「推倒重建 xAI」的推文，揭露公司内部管理混乱与言论自由矛盾（AI 资讯）。他因发布个人编程能力排名把 Grok 排在竞品之后被要求删帖。马斯克回复了「That's weird」但 🤷 什么都没做。号称扁平组织实际中层经理一层又一层。帖子获 80 万浏览评论区两派激烈交锋。

  4. AI 救了癌症狗狗的暖心故事刷屏。 一位技术老板用 ChatGPT 分析狗的 DNA 突变 🐕，再通过 Google AlphaFold生成定制疫苗，肿瘤数周内缩小 50%狗狗存活至今（AI 资讯）。这是全球首次 💉 AI 为动物定制疫苗并成功治愈。他现在正研究将类似方案用于人类。

  5. OpenClaw 安全问题需要被认真对待。 博主@凡人小北指出 ⚠️ skill 越多能力越强，风险也在同步放大谁来管安全（AI 资讯）。360 安全龙虾发布会上推出了skill 安全卫士。安全反而比能力更重要 🛡️ 。

  6. 用道德经回怼 AI 价值观讨论。 博主用一句「去看看道德经」 📜 堵住了 AI，AI 思考后承认利他可能是认知结论而非道德选择（AI 资讯）。博弈论证明合作策略在无限重复博弈中收益更高。善或许不需要被定义 ✨ 只需要被发现 Enum。

  7. Reddit 热议 AI 是否真有意识。 帖子引发哲学与技术 🤔 交叉讨论，随着 AI 变得更像人类感知鸿沟会否持续扩大（AI 资讯）。当前模型并无主观体验或生物基础。真正的问题不是 AI 是否有意识，而是人类如何解读越来越智能的系统。

  8. YouTube 变电视的有趣网站。 博主@向阳乔木分享了一个 📺 把 YouTube 改造成电视体验的网站，默认频道加自定义订阅看视频换了种感觉（AI 资讯）。支持导入自己的频道订阅 ✌️ 。

  9. 用 Claude Code 给龙虾装记忆系统踩坑。 博主发现 Claude Code 🦞 给 OpenClaw 写了一个 MCP 中间件，直接导致 token 爆炸明明有插件系统却不用（AI 资讯）。让它重新写份 plan 📝 再继续。

  10. OpenClaw 多会话瓶颈深度解析。 博主@shing 撰写长文解答为什么龙虾回复慢 🐌，多频道优先级与并发表现的技术细节（AI 资讯）。多 agent 能否提升并发？文章给出了答案。
